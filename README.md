# AMOS — تقرير الصيانة (تطبيق PWA)

تطبيق ويب قابل للتثبيت على الجوال والكمبيوتر، يعمل بدون إنترنت بعد أول فتحة.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق نفسه (نفس النسخة السابقة + زر التثبيت) |
| `manifest.json` | بطاقة تعريف التطبيق: الاسم، الأيقونات، الألوان، وضع standalone |
| `sw.js` | Service Worker — التخزين المؤقت والعمل بدون إنترنت + إشعار التحديث |
| `icon-192.png` / `icon-512.png` | أيقونات التطبيق |
| `icon-maskable-512.png` | أيقونة أندرويد (Adaptive icon) |
| `favicon.ico` | أيقونة تبويب المتصفح |
| `amos-logo.svg` | شعار AMOS كملف SVG متجهي (للاستخدام في مستندات أخرى) |

> ⚠️ لا يعمل التثبيت عند فتح الملف مباشرة بالنقر المزدوج (`file://`).
> لا بد من رفعه على رابط **https**.

---

## الرفع على GitHub Pages

1. أنشئي مستودعًا جديدًا (مثلاً `AMOS-REPORT`) واجعليه **Public**.
2. ارفعي **جميع** ملفات هذا المجلد في جذر المستودع (وليس داخل مجلد فرعي).
3. `Settings` → `Pages` → في `Source` اختاري `Deploy from a branch` → الفرع `main` والمجلد `/ (root)` → `Save`.
4. انتظري دقيقة، ثم افتحي الرابط:
   `https://<اسم-حسابك>.github.io/AMOS-REPORT/`

## أو الرفع على Netlify Drop (أسرع طريقة)

افتحي <https://app.netlify.com/drop> واسحبي المجلد كاملًا إلى الصفحة — يعطيكِ رابط https فورًا.

## طريقة التثبيت على الجهاز

**أندرويد / كروم / إيدج (جوال أو كمبيوتر):**
يظهر زر **«📲 تثبيت التطبيق»** في شريط التطبيق العلوي — اضغطيه ثم «تثبيت».
أو من قائمة المتصفح ⋮ → «تثبيت التطبيق» / «Install app».

**آيفون / آيباد (سفاري فقط):**
زر المشاركة ⬆️ في أسفل الشاشة → «إضافة إلى الشاشة الرئيسية».
(زر التثبيت داخل التطبيق سيعرض لكِ هذه الخطوات.)

**ويندوز (كروم / إيدج):**
أيقونة التثبيت ⊕ في نهاية شريط العنوان → «تثبيت».

بعد التثبيت يفتح التطبيق في نافذة مستقلة بدون شريط عنوان المتصفح، وتُحل معه مشكلة معاينة الطباعة في إيدج.

## عند تحديث التطبيق مستقبلًا

بعد أي تعديل على `index.html`، غيّري رقم الإصدار في أول سطر من `sw.js`:

```js
const CACHE_VERSION = 'amos-report-v1.1.1';   // ارفعي الرقم
```

بدون ذلك ستبقى النسخة القديمة مخزّنة في أجهزة المستخدمين.
عند رفع نسخة جديدة يظهر للمستخدم شريط سفلي «يتوفر إصدار جديد» مع زر «تحديث».

## ملاحظات

- ملف قراءة الإكسل (SheetJS) يُخزَّن محليًا عند أول تشغيل، فيعمل التطبيق بدون إنترنت.
- جميع البيانات تُعالَج داخل الجهاز فقط، ولا يُرفع أي ملف إكسل إلى أي خادم.
- بيانات تسجيل الدخول لا تزال داخل ملف `index.html` كما هي — لا تنشري المستودع إن كنتِ تعتبرينها سرّية، أو استخدمي مستودعًا خاصًا مع Netlify.
